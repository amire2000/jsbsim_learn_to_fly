# JSBSim Learn to Fly

Learn fixed-wing physics and JSBSim through a Mini Plank simulation.

## Course target

By the end, you will be able to model and evaluate aircraft motion with JSBSim,
coordinate experiments in Python, and display the results in Godot.

## Who it is for

For a Python-proficient learner new to aviation, flight physics, and Godot.

Start with [Module 0: Orientation](modules/00-orientation/index.md), then use
the [roadmap](roadmap.md) and [syllabus](syllabus.md) to plan the track.
