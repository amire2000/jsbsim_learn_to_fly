# Contributing

How to contribute to the JSBSim Learn to Fly documentation.

## How to Contribute

We welcome contributions! Whether you're fixing typos, improving examples, or adding new content:

1. **Fork** the repository
2. **Create** a branch for your change
3. **Make** your changes
4. **Submit** a pull request

## Reporting Issues

Found a bug or unclear content? [Create an issue](https://github.com/your-repo/jsbsim-learn-to-fly/issues) on GitHub.

## Getting Help

- Check existing [issues](https://github.com/your-repo/jsbsim-learn-to-fly/issues)
- A project Code of Conduct has not yet been published.
- Ask in the [Discussions](https://github.com/your-repo/jsbsim-learn-to-fly/discussions)

## Code Style

- Follow existing formatting conventions
- Use consistent naming
- Include examples with code snippets
- Test your changes before submitting
