# Roadmap

## Final goal

Describe the practical capability learners will build.

| Milestone | Modules | Outcome |
| --- | --- | --- |
| Foundation | 0 | Learn the first essential concept. |
| Capstone | 1+ | Apply the concepts to a real task. |

## Recommended sequence

1. Start with Module 0.
2. Keep each lesson focused on one new idea.
3. Validate each idea with a small example before integrating it into the capstone.
